# Game 2048 

**Боровский Максим Олегович · 367916 · К3344**

Небольшой учебный проект (чистый HTML/CSS/JS). Браузерная версия игры 2048 с сохранением состояния, таблицей лидеров и адаптивной версткой под десктоп и мобильные устройства.

## Функционал
Функционал
Игровое поле 4×4 генерируется динамически с помощью JavaScript
- Движение плиток во все четыре стороны (вверх, вниз, влево, вправо)
- Слияние одинаковых плиток по правилам 2048 
- Начальная генерация 1-3 случайных плиток со значением 2 или 4
- После каждого хода появляется 1-2 новых плитки (2 или 4) в случайных свободных ячейках
- Корректный подсчёт и отображение текущего счёта (сумма значений объединённых плиток за ход)
- Проверка окончания игры (отсутствие возможных ходов) и показ оверлея с сообщением
- Кнопка "Начать заново" сбрасывает поле и счёт без перезагрузки страницы
- Кнопка "Отменить ход" (undo) возвращает состояние на один шаг назад (если игра не окончена)
- Сохранение состояния игры в localStorage (поле, счёт, состояние окончания, возможность продолжить с последнего хода)
- Сохранение таблицы лидеров в localStorage
- Экран ввода имени при окончании игры и сохранение рекорда (имя, количество очков, дата)
- Просмотр таблицы топ-10 лидеров в отдельном модальном окне
- Разное управление на разных устройствах:
  - на десктопе - стрелки на клавиатуре
  - на мобильных - экранные кнопки (вверх / вниз / влево / вправо), скрываются при просмотре рекордов
